# Historical Intelligence report (Power BI)

**Automated:** the Direct Lake semantic model `sm_mvoi_historical` (TMDL in
`fabric/semantic-model/`, generated by `mvoi.deploy.semantic`, deployed by
`deploy_fabric.py --steps semantic`). Tests check its columns against the real
Spark Gold schemas.

**Manual:** the report canvas. Build it once in the browser (about 30–45 min),
then save it into the `30 - Data Products` folder as `rpt_mvoi_historical`.
After you commit from Fabric Git, the report's PBIR lands in `/workspace`.

## Model

Star schema. Dimensions: **Date**, **Site**, **Corridor**. Facts:
Incidents (distinct occurrences), Corridor Daily, Site Disruption, Site
Proximity, Weather Exposure, Pipeline Health, Data Quality. Incident Weather
bridges Incidents to NWS alerts. Hot Spots is a standalone map table.
Relationships are single-direction, many-to-one. Implicit measures are
discouraged.

Deliberate deviations from the modeling guidelines:
* latitude/longitude, Gi* z/p values and minutes stay `double`, because Direct
  Lake uses the Delta type as-is and geographic precision matters;
* Hot Spots has no relationships. Grid bins have no date or site, and the
  table is a map layer.

## Pages

Create these slicers on every page and sync them: **Date[Date]** (between),
**Corridor[Corridor]**, **Incidents[Event Type]**, **Site[Site]**.

### 1. Overview
| Visual | Fields |
|---|---|
| Cards | `Incident Occurrences`, `Road Closure Occurrences`, `Incident Hours`, `Weather-Related Share`, `Sites Under Alert` |
| Line chart | X: Date[Date]; Y: `Incident Occurrences`; legend: Incidents[Peak Severity] |
| Clustered bar | Y: Corridor[Corridor]; X: `Incident Occurrences`, `Closure Hours` |

### 2. When incidents happen
| Visual | Fields |
|---|---|
| Matrix heat map | Rows: Date[Day of Week]; columns: Incidents[Start Hour]; values: `Incident Occurrences`; background colour by value |
| Column chart | X: Date[Year Month]; Y: `Incident Occurrences`, `Average Duration Minutes` |

### 3. Where — hot spots
| Visual | Fields |
|---|---|
| Azure Maps (or ArcGIS for Power BI) | Lat: Hot Spots[Bin Latitude]; Long: Hot Spots[Bin Longitude]; colour: Hot Spots[Confidence] (diverging, −3 blue … +3 red); filter Confidence ≠ 0 |
| Azure Maps layer 2 | Lat/Long: Site[Latitude]/[Longitude]; tooltip: Site[Site], `Peak Exposure Score` |
| Table | Hot Spots[Confidence], `Hot Spot Bins 95`, `Occurrences in Hot Spots` |

ArcGIS for Power BI can draw the exact bin polygons from Hot Spots[Bin WKT],
if your tenant allows that visual.

### 4. Weather correlation
| Visual | Fields |
|---|---|
| Card | `Weather-Related Share` |
| Stacked column | X: Date[Year Month]; Y: `Weather-Related Occurrences`, `Incident Occurrences` |
| Table | Weather Exposure[Weather Event], [CAP Severity], Site[Site], [Onset], [Expires] |

Footnote on the page: *Coincidence in space and time, not proven causation.*

### 5. Site disruption
| Visual | Fields |
|---|---|
| Line chart | X: Site Disruption[Scored At]; Y: `Peak Exposure Score`; small multiples: Site[Site] (top 6 by criticality) |
| Table | Site[Site], Site[Criticality], `Peak Exposure Score`, `High Exposure Snapshots`, `Nearby Incident Occurrences`, `Average Distance Miles`, `Weather Share of Exposure` |
| Table (drill-through) | Site Disruption[Scored At], [Band], [Explanation] |

Page subtitle: *Scores are inferred travel-disruption exposure from public data; MVOI is not affiliated with any site.*

### 6. Pipeline health & data quality
| Visual | Fields |
|---|---|
| Cards | `Poll Success Rate`, `Rejected Record Rate`, `P95 End to End Latency Seconds`, `DQ Pass Rate` |
| Line chart | X: Date[Date]; Y: `Total Polls`, legend: Pipeline Health[Source] |
| Table | Data Quality[Rule], [Rule Severity], `DQ Failed Rows` |

## Refresh behaviour

| Experience | Refresh | Interaction |
|---|---|---|
| Real-Time Dashboard | Live updates every 10 s minimum (30 s fallback) while open | Cross-filter, drill-through, parameter (Live/Replay); bubble map shows points only |
| Power BI (Direct Lake) | Sees Gold as soon as the hourly pipeline commits; no scheduled refresh | Full slicing, drill-through, Azure Maps / ArcGIS polygons; not second-level live |
| ArcGIS notebook map (`st.plot`) | Static image produced when the notebook runs | Analyst-oriented; not interactive |
